اختيار المعيار هنا يحدد مرجع المراجعة فقط. لم تُحمّل بعد جداول سعات التيار أو شروط الحماية المعتمدة؛ لذلك لا يصدر التطبيق اعتماداً نهائياً لمقطع الكابل أو القاطع.

قائمة المواد – نموذج أولي

تُبنى القائمة النهائية بعد إدخال كتالوج المنتجات المعتمد لديك ومراجعة متطلبات الحماية الخاصة بالشاحن والموقع.

لا تختَر القاطع أو RCD أو SPD أو المفتاح أو المقبس اعتماداً على التيار وحده. يجب التحقق من تعليمات مصنع الشاحن، ونظام التأريض، وحماية DC 6 mA أو RCD Type B عند الاقتضاء، وقدرة القطع، وعدد الأقطاب، والتنسيق مع الحماية العليا.
  • كابل تغذية مناسب بعد التحقق من السعة الحرارية وهبوط الجهد
  • قاطع حماية معتمد ومتوافق مع الكابل
  • RCD / RCBO وفق متطلبات الشاحن والنظام
  • SPD عند الحاجة وفق تقييم الموقع والكود
  • مفتاح فصل، صندوق حماية، جلاند، أطراف، مواسير
  • موصل حماية PE وربط تساوي الجهد حسب التصميم

نسخة أولية للحسابات المساعدة. لا تستخدم النتائج وحدها لتنفيذ التركيب أو اختيار وسيلة الحماية. يلزم التحقق من جداول المعيار المحلي وبيانات المصنع والقياسات بالموقع.
